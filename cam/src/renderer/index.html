Caméra
Définition
Images/s

Webcam, carte d'acquisition ou caméra virtuelle (Camo, Iriun…). Une autre application qui l'utilise déjà (Discord, OBS, Teams) peut la bloquer.

Caméra
Qualité
Connexion de l'iPhone
  1. iPhone sur le même Wi-Fi que ce PC.
  2. Scanne le code avec l'appareil photo.
  3. « Connexion non privée » : Afficher les détails › visiter ce site web.
  4. Touche Démarrer et autorise la caméra.
Carte réseau

Au premier lancement, Windows demande l'accès au réseau : autorise les réseaux privés.

Si un pare-feu est actif (ufw, firewalld…), ouvre-lui les ports 8443 et 8080.

Cadrage
Forme et recadrage

Recadre en zoomant puis en déplaçant le point de visée. Double-clic sur un curseur : valeur par défaut.
